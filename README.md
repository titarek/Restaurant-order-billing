# Restaurant Order & Billing Management System

A simple restaurant order and billing management system built with React, Node.js, Express.js and MySQL.

## Features

- View menu items
- Select food items
- Manage quantities
- Create customer orders
- Automatic bill calculation
- Sales and order history
- Inventory management
- Stock updates
- Add menu items
- Delete menu items
- Sales summary

## Technologies

- React.js
- Node.js
- Express.js
- MySQL
- HTML
- CSS
- JavaScript

## Run Frontend

```bash
cd frontend
npm install
npm run dev
